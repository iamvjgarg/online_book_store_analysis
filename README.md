# 📚 Online Bookstore Data Analysis – SQL

## 📌 Project Overview
A SQL-based data analysis project focused on exploring an online bookstore's data, including books, customers, and orders to generate meaningful business insights.

## 📊 Analysis Covered
- Book and Customer Analysis
- Order and Sales Analysis
- Revenue Analysis
- Bestselling Books
- Customer Purchase Patterns
- Business Performance

## 🛠️ Tools Used
- SQL
- Data Querying
- Joins
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)

## 🎯 Objective
To analyse bookstore data using SQL and extract valuable insights into sales, customer behaviour, and business performance.
